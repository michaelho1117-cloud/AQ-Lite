# knowledge/private（不进 git）

这里放**只属于你自己**的上下文，文件会被 `.gitignore` 忽略，永远不会推到公开仓库：

- `context_YYYY-MM-DD.md`：当前持仓、总资产、现金、在看的盘、没定的问题。
- `trading_style.md`：你的交易风格、纪律和已知毛病（让模型能当面提醒你）。

模型启动时会读这里；文件不存在时，它应该先问你资产、现金和持仓，而不是自己猜。

模板：

```markdown
# 当前处境（YYYY-MM-DD）
- 总资产约 $____，现金约 $____
- 持仓：<盘> <YES/NO> <份数> @<均价>
- 在看：<盘>（原因）
- 没定的问题：……
```
